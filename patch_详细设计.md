  1. 功能概述                                                                                                                                                                                                                    
                                                                                                                                                                                                                                 
  用途：对比高低版本的升级包，生成差异补丁文件                                                                                                                                                                                   
                                                                                                                                                                                                                                 
  输入：                                                                                                                                                                                                                         
  - service-name: 服务名（如 aispl、baas）
  - 可选：指定比较的目录（默认自动检测）                                                                                                                                                                                         
   
  输出：                                                                                                                                                                                                                         
  - lib_patch/ 目录：包含差异文件
  - lib_patch/patch_meta_info.json：版本元数据

  3. 文件对比逻辑详解

  高版本目录 vs 低版本目录 → lib_patch/
  ─────────────────────────────────────────────────────────────                                                                                                                                                                  
  lib/          合并替换: 只复制有变化的 jar                                                                                                                                                                                     
  conf/         合并替换: 只复制有变化的配置文件                                                                                                                                                                                 
  web/          全量替换: 复制整个 web 目录                                                                                                                                                                                      
  bin/          合并替换: 只复制有变化的文件
  plugins/      合并替换: 只复制有变化的文件                                                                                                                                                                                     
  elk/          合并替换: 只复制有变化的文件                                                                                                                                                                                     
  input/        合并替换: 只复制有变化的文

  4. 特殊处理
                                                                                                                                                                                                                                 
  dist.jar 处理 (lib 目录)：
  # 高版本的 dist.jar 会被复制                                                                                                                                                                                                   
  lib/ailpha-ext-aispl-v1.1.0.23_aisplweb_dev-xxx-dist.jar                                                                                                                                                                       
                                                                                                                                                                                                                                 
  # 低版本的 dist.jar 会被加入 excludes 列表                                                                                                                                                                                     
  # 最终在创建镜像时删除                                                                                                                                                                                                         
                                                                                                                                                                                                                                 
  web 目录：                                                                                                                                                                                                                     
  - 整体复制高版本 web 目录到 lib_patch/web/                                                                                                                                                                                     
  - 创建镜像时执行全量替换

● create_patch_image.sh 脚本流程详解                                                                                                                                                                                             
                                             
  1. 功能概述                                                                                                                                                                                                                    
                                                                                                                                                                                                                                 
  用途：基于已有的 Docker 镜像，通过补丁文件创建新的服务镜像                                                                                                                                                                     
                                                                                                                                                                                                                                 
  输入：                                                                                                                                                                                                                         
  - service-name: 服务名（如 aispl-web）
  - target-path: 容器内目标路径（可选，默认 /usr/hdp/2.5.3.0-37/aispl/aisplweb）                                                                                                                                                 
                                                                                
  输出：                                                                                                                                                                                                                         
  - 新镜像 ailpha-registry:5000/${service}:${targetVersion}

  4. 删除逻辑详解 
                 
  A. excludes 删除（来自 patch_meta_info.json）
  {                                                                                                                                                                                                                              
    "excludes": [
      "lib/ailpha-ext-aispl-v1.1.0.20_aisplweb_dev-xxx-dist.jar",                                                                                                                                                                
      "lib/baas-lang-5.2.0-20260422.075305-12.jar"               
    ]                                             
  }  
  执行: 删除容器内 $TARGET_PATH/lib/ 下这些旧文件
                                                 
  B. 差异同步删除（对比 extract/low 和 extract/high）                                                                                                                                                                            
  extract/low 有但 extract/high 没有的文件 → 从容器中删除                                                                                                                                                                        
  确保新镜像不会残留低版本独有的文件
